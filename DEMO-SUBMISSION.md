# uMaqoma demo delivery

Open the workspace and choose **Open uMaqoma demo draft**. This creates a separate browser-local project. Story stewardship links sources to scenes, panels and artwork. In Comic pages, select a panel and edit narration; the shared source feeds the reader and animatic. Reader preview opens a separate print-review tab. Export project produces a portable JSON backup with images.

Delivered: 12 story pages (24 panel placements), cover, two notes/credits pages; 1,616 isiXhosa story words. Existing artwork was reused after the creator requested image generation stop. All 26 asset records remain drafts, including reused illustrations and the reference sheet. No artwork has been approved on the creator's behalf.

Verification: 23 Node tests pass. A fresh headless Edge browser opened the demo and visited Story, Bible, Assets, Stewardship, Storyboard, Animatic, Composer, Languages and Reader without JavaScript errors. Export produced 15 PDF pages, all images loaded, no page overflow detected; all pages rendered for contact-sheet inspection. Provider success/error responses were mocked; no live-key historical request was made.

Limitations: this is a demo draft, not a publication-ready history. Fluent-speaker and historical/costume review remain outstanding. Some generated compositions repeat the reference-sheet faces; some later panels reuse earlier artwork. These are interpretive images, never archival evidence. Full mobile and every destructive workflow were not re-rehearsed in this increment. Interface isiXhosa remains partial and unvalidated. Browser storage is device-local; export backups. The live fiction coordinator is blocked for this history demo, while the local helper remains available. No claim of cultural authenticity, legal readiness or permission verification is made.

Research and source disagreements are recorded in content/maqoma/research.json. The manuscript is in content/maqoma/manuscript.txt. The public review edition contains selected acknowledgements, not private stewardship notes.
